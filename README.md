# Инструкция по начальной настройке

## Назначение

Документ описывает порядок действий в информационной базе, в которой ведётся реальный учёт, для начала работы с новой функциональностью (управленческий расчёт зарплаты, планирование отпусков, обслуживание клиентов, отчёты).

Все действия выполняются в режиме **1С:Предприятие**. Перед началом рекомендуется создать резервную копию базы данных.

---

## 1. Заполнение констант

### 1.1. Номенклатура для автозаполнения реализаций

Откройте: **Все функции → Константы → НоменклатураАбонентскаяПлата**.

- Выберите элемент справочника `Номенклатура`, который будет использоваться для строки абонентской платы (например, «Абонентская плата»).
- Запишите и закройте.

Откройте: **Все функции → Константы → НоменклатураРаботыСпециалиста**.

- Выберите элемент справочника `Номенклатура`, который будет использоваться для строки работ специалиста (например, «Работа специалиста»).
- Запишите и закройте.

> ⚠️ **Важно:** без заполнения этих констант автозаполнение документов «Реализация товаров и услуг» работать не будет.

### 1.2. Настройки телеграм-бота

Откройте: **Все функции → Константы → ТокенУправленияТелеграмБотом**.

- Введите токен, полученный у @BotFather в Telegram.
- Запишите и закройте.

Откройте: **Все функции → Константы → ИдентификаторГруппыДляОповещения**.

- Введите ID группы (чата), в которую будут отправляться уведомления.
- Запишите и закройте.

> ⚠️ **Важно:** без этих настроек регламентное задание отправки уведомлений работать не будет.

## 2. Настройка справочников

### 2.1. Сотрудники

Справочник **Сотрудники** должен содержать всех работников предприятия. Для каждого сотрудника должны быть указаны:

- ФИО.
- Организация.
- Должность.

### 2.2. Условия оплаты сотрудников

Откройте: **Все функции → Регистры сведений → УсловияОплатыСотрудников**.

Для каждого сотрудника заполните записи с периодичностью **Месяц**:

- **Оклад** — минимальный оклад (для специалистов — минимальный оклад).
- **ПроцентОтРабот** — процент от выполненных работ (только для специалистов; для административного персонала — 0).

> ⚠️ **Важно:** если для специалиста не установлен процент от работ, документ «Обслуживание клиента» не будет проведён (за исключением случая, когда процент явно установлен в 0).

### 2.3. Договоры с контрагентами

Справочник **ДоговорыКонтрагентов** должен содержать договоры с новыми реквизитами:

- **ВидДоговора** — выбрать «Абонентское обслуживание».
- **ДатаНачалаДействия** — дата начала действия договора.
- **ДатаОкончанияДействия** — дата окончания действия договора.
- **СуммаАбонентскойПлаты** — ежемесячная сумма абонентской платы.
- **СтоимостьЧасаРаботы** — стоимость часа работы специалиста.

Эти реквизиты **обязательно** заполнять для договоров абонентского обслуживания. Иначе документы «Обслуживание клиента» и «Реализация товаров и услуг» не будут работать корректно.

### 2.4. Виды договоров

Справочник (перечисление) **ВидыДоговоровКонтрагентов** должен содержать новый элемент:

- **Абонентское обслуживание**.

## 3. Назначение ролей пользователям

Откройте: **Администрирование → Пользователи**.

Для каждого пользователя назначьте соответствующую роль (профиль):

| Роль / Профиль | Кому назначать | Что даёт |
|---|---|---|
| **Специалист** | Специалисты, выполняющие работы | Работа с документом «Обслуживание клиента», просмотр отчёта «Выработка специалистов» |
| **Менеджер** | Менеджеры | Создание и планирование заявок, работа с документом «Обслуживание клиента» |
| **БухгалтерИТФирмы** | Бухгалтеры | Работа с «Реализацией товаров и услуг», отчёт «Анализ выставленных актов», массовое создание актов |
| **КадровикРасчетчик** | Кадровики-расчётчики | Работа с «Графиком отпусков», «Начислением зарплаты», отчётами по зарплате и отпускам |

> ⚠️ **Важно:** роли и профили должны быть предварительно созданы в конфигурации. Если профили не созданы — создайте их в режиме «Конфигуратор» (или используйте уже существующие).

## 4. Настройка подсистемы «Обслуживание клиентов»

### 4.1. Проверка размещения объектов

Убедитесь, что объекты, связанные с обслуживанием клиентов, находятся в подсистеме **Обслуживание клиентов**:

- Документ `ОбслуживаниеКлиента`.
- Обработка `КалендарьСпециалистов`.
- Обработка `МассовоеСозданиеАктов`.
- Регистр `ВыполненныеКлиентуРаботы`.

### 4.2. Подключение подключаемых команд

На формах документов «Обслуживание клиента» должны быть подключены подключаемые команды (стандартная функциональность БСП).

### 4.3. Хранение присоединённых файлов

Убедитесь, что у документа «Обслуживание клиента» есть возможность хранить присоединённые файлы (скан/фото листа учёта рабочего времени).



## 6. Проверка работы механизмов

### 6.1. Проверка документа «Обслуживание клиента»

1. Создайте новый документ.
2. Заполните: Клиент, Договор (вид — абонентское обслуживание), Специалист, Дата, Время, Описание проблемы.
3. Заполните табличную часть «Выполненные работы» (описание, часы).
4. Проведите документ.

**Ожидаемый результат:**
- Документ проведён.
- В регистре `ВыполненныеКлиентуРаботы` есть движения.


### 6.2. Проверка документа «Начисление зарплаты»

1. Создайте документ.
2. Укажите период (месяц).
3. Заполните (если есть автозаполнение) или вручную добавьте сотрудников.
4. Проведите документ.

**Ожидаемый результат:**
- В регистрах `ОсновныеНачисления`, `Удержания`, `ВзаиморасчетыССотрудниками` есть движения.
- НДФЛ рассчитан автоматически.

### 6.3. Проверка документа «График отпусков»

1. Создайте документ.
2. Укажите год.
3. Добавьте строки: Сотрудник, Дата начала, Дата окончания.
4. Проведите документ.

**Ожидаемый результат:**
- В регистре `ОстаткиОтпусковСотрудников` есть движения (Приход).
- Строки с длительностью более 28 дней подсвечены на форме.

### 6.4. Проверка отчётов

Откройте каждый отчёт и убедитесь, что он формируется без ошибок:

- **Выработка специалистов** — доступен специалистам и кадровикам-расчётчикам.
- **Анализ выставленных актов** — доступен бухгалтерам.
- **Расчёты с сотрудниками** — доступен кадровикам-расчётчикам.
- **Расход запланированных отпусков** — доступен кадровикам-расчётчикам.

---

## 7. Проверка прав доступа

Для каждого пользователя убедитесь, что он видит только те объекты и отчёты, которые ему разрешены:

| Пользователь | Что должен видеть | Что не должен видеть |
|---|---|---|
| Специалист | Обслуживание клиентов, отчёт «Выработка специалистов» | Зарплата, отпуска |
| Менеджер | Обслуживание клиентов | Зарплата, отпуска |
| Бухгалтер | Реализация товаров и услуг, отчёт «Анализ выставленных актов» | Обслуживание клиентов |
| Кадровик-расчётчик | Зарплата, отпуска, отчёты по зарплате и отпускам | Обслуживание клиентов |

---

## 8. Дополнительные рекомендации

- Перед началом работы убедитесь, что **все пользователи вышли из программы** (или работают в монопольном режиме при обновлении).
- После обновления конфигурации **выполните обновление конфигурации базы данных** (F7 в конфигураторе).
- При возникновении ошибок — проверьте журнал регистрации (**Администрирование → Журнал регистрации**).

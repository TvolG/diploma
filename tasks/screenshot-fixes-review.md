| Ошибка | Объект и участок | Причина и решение |
|---|---|---|

| Выбор чужого договора в обслуживании | `Documents/ВКМ_ОбслуживаниеКлиента/Forms/ФормаДокумента/Module.bsl`, модуль объекта | Отбор по клиенту и виду; очистка несовместимого выбора; серверная проверка клиента, вида и дат защищает также программную запись. |
| Обязательное отдельное заполнение массового создания | `DataProcessors/ВКМ_МассовоеСозданиеАктов`, формы и объект | Создание само обновляет список договоров; исполнение вынесено в длительную операцию БСП. |
| Дубли строк реализации при повторном запуске | `Documents/РеализацияТоваровУслуг/ObjectModule.bsl`, менеджер массового создания | Перед автозаполнением очищаются услуги, работы агрегируются в одну строку; существующий акт по договору/месяцу пропускается под блокировкой. |
| Нет раздела зарплаты у администратора | `Subsystems/ВКМ_ЗарплатаИОтпуска`, Configuration, роли | Подсистема включена в интерфейс; добавлены документы, отчёты и команды; полные права не зависят от назначения кадрового профиля. |
| Кадровик не может запустить клиент | `Roles/ВКМ_КадровикРасчетчик`, `CommonModules/УправлениеДоступомИТ/Module.bsl` | Поставляемый профиль включает базовые роли запуска и работы БСП. Проверять после обновления профилей и повторного входа. |
| Начисления вводились готовыми суммами | `Documents/ВКМ_НачислениеЗарплаты`, `CommonModules/ВКМ_РасчетЗарплаты`, регистры и планы видов расчёта | Введены вид и периоды начисления, календарь, фактический период действия, вытеснение оклада отпуском и база за 12 месяцев. Суммы, НДФЛ и сумма выплаты рассчитываются, денежные результаты формы недоступны для ручного редактирования. |
| Завышенная выплата | `Documents/ВКМ_ВыплатаЗарплаты/Forms/ФормаДокумента/Module.bsl` | Вместо суммирования физических движений используются положительные остатки перед моментом документа; для нового документа — граница даты. |
| `Поле объекта не обнаружено (УсловноеОформление)` | `Documents/ВКМ_ГрафикОтпусков/Forms/ФормаДокумента/Module.bsl` | Оформление принадлежит форме; создаётся на сервере, итог дней рассчитывается по сотруднику по всем строкам. |
| `Метод объекта не обнаружен (Очистить)` | Там же, `УстановитьУсловноеОформление` | У объекта условного оформления нет метода `Очистить`. Коллекция очищается через `УсловноеОформление.Элементы.Очистить()`. Отдельный опубликованный коммит: `60a98ef9b77dc59c2cebb426cefa4d69e60221e3`. |
| Анализ графика: оставшиеся обработчики | `Documents/ВКМ_ГрафикОтпусков/Forms/АнализГрафика` | Удалены ссылки на отсутствующие `ПриОткрытии` и `ОткрытьГрафик`. Диаграмма строится при создании на сервере, год передаётся параметром, данные — временным хранилищем. |
| Отчёт падает при отключении даты | `Reports/ВКМ_АнализАктов`, DCS и ObjectModule | Стандартный период задаёт обязательные границы всегда; техническая номенклатура берётся из константы с проверкой. |
| Неверные суммы и подписи отчёта | Там же; `AccumulationRegisters/ВКМ_ВыставленныеАкты`; модуль реализации | Источник факта — регистр актов; объединение агрегируется по клиенту и договору без размножения строк. Факт учитывает только работы, исключая абонплату и прочие услуги. Подписи «Сумма работ», «Сумма акта». |
| Нет команд просмотра движений | Формы новых документов | Добавлены команды перехода к движениям регистров. Для обслуживания подключены стандартные команды/присоединённые файлы БСП. |

Клиентские обработчики отвечают за интерфейс, запросы и запись выполняются на сервере. Ограничения выбора повторены при записи/проведении. Новые регистры указаны в метаданных документов-регистраторов. Типы и ссылки проверены статически. Нативное выполнение перечисленных решений ещё не подтверждено на платформе — см. [проверки](../docs/checks.md).

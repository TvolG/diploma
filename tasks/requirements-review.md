# Сопоставление с ТЗ

Источник: `netology-code/fonecmid-diplom`, коммит `2d65c44bdd535706075d35b96fbfabf3b540363f`. Telegram исключён по прямому указанию заказчика. Исходный файл задания `telegram.md` и штатные интеграции поставщика не являются реализацией этой задачи и не изменяются.

|---|---|---|
| Договоры абонентского обслуживания | Реквизиты, программная группа формы, видимость/порядок, серверные проверки | Открытие старого/нового договора, смена вида |
| Обслуживание и присоединённые файлы | Планирование, часы, проверки, БСП, два регистра стоимости работ | Работа трёх профилей, файл и повторное проведение |
| Массовые акты | Стандартное заполнение, проверка заполнения, блокировка и пропуск существующих, фон БСП | Фоновый вызов, два последовательных и одновременных запуска |
| Печать акта | Подключаемая печать БСП и редактируемый общий макет | Печать/редактирование макета и права |
| Управленческая зарплата | Виды расчёта, календарь, периоды, база/вытеснение, оклад/процент/отпуск, премии и НДФЛ | Загрузка EDT, поля виртуальных таблиц, результаты расчёта и перерасчёт |
| Выплата | Остатки на момент документа, очистка повторных движений | Даты и перепроведение |
| План отпусков | Год, дни, суммарное выделение >28, диаграмма Ганта | Открытие и изменение строк/интервалов |
| Четыре отчёта | Источники только регистры, стандартный период/год, корректные смыслы сумм | Компоновка, отборы, минимум 10 строк в демонстрации |

| Правила расширения | Префиксы корневых объектов с сохранением UUID, скрытая подсистема, выделение добавлений | Сравнение и загрузка в EDT без потерь данных |
| Начальная настройка | Обработка настройки, README, шаблон календаря, виды расчёта | Применение к копии действующей базы |
| Демонстрационные данные | Генератор с блокировкой, история расчётов и данными для отчётов, тестовые пользователи | Реальный запуск, обязательные поля справочников, количество строк, открытие файлов |
| Автотест | Сценарий в `tests/features`, отдельный числовой эталон | Запись/уточнение интерфейсных шагов на платформе, запуск Vanessa и протокол |
| DT в релизе | Инструкция и скрипт экспорта после проверки | Создать актуальную базу, прогнать сценарии, выгрузить и приложить DT |

Ограничения текущего расчёта: один документ начисления на сотрудника в месяц; отпуск по месяцам разделяется строками/документами, исходный период работ задаётся отдельно. Исправления прошлого требуют хронологического перепроведения начислений командой обработки; выплаты не перепроводятся автоматически. Эти ограничения явно проверяются и не скрывают несовместимые данные.

Платформа 1С/EDT отсутствует в среде разработки. Поэтому статус «исходники подготовлены» не означает завершённую приёмку ТЗ. Не выполнены здесь: нативная компиляция, интерактивные прогоны, проверка профилей, фактическое создание демобазы, запуск Vanessa, новая выгрузка DT. Старый DT не переопубликован под видом нового.
